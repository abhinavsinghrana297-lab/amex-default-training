1. AmEx Credit Default / Fraud Detection
Python, Polars, XGBoost/LightGBM, FastAPI, Docker, GitHub Actions

Built an end-to-end credit default prediction system on a 16GB+ transactional dataset (American Express Kaggle competition); engineered a memory-efficient data pipeline using Polars, benchmarked 3 classification models (Logistic Regression, XGBoost, LightGBM) under class imbalance, and deployed the best-performing model as a FastAPI inference service, containerized with Docker and automated via GitHub Actions CI/CD.
